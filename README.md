# Soul Leveling: Shadow Monarch (Cinematic Real-Life Edition)

An ultra-realistic, cinematic HTML5 3D-perspective action game inspired by Solo Leveling. Features dark dungeon environments, blue aura blade slashes, shadow soldier extractions, and mobile touch controls.

## Deploy & Play
1. Upload these files to your GitHub Repository.
2. Enable GitHub Pages to get your instant live mobile URL.
3. Open on your mobile phone and play like a native app!
